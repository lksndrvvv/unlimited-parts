# Практическая работа 2.2

## Kanban

В проекте настроена Kanban-доска со статусами:

- New
- Approved
- Committed
- QA Doing
- QA Done
- Done

Для QA Doing используется ограничение WIP = 1.

Для рабочих элементов используются labels:

- data
- ux
- development
- design
- expedited
- bug

Для приоритетных задач используется значение:

Priority = Expedited

Для QA используется критерий выполнения:

Definition of Done: Проходят все тесты.
