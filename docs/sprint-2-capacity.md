# Sprint 2 Capacity

## Участник

Студент проекта PUL-Web.

## Рабочая емкость

Нагрузка: 1 час в рабочий день.

Исходная доступная емкость: 8 часов.

## Планируемые задачи

1. Добавить страницу для самых последних учебников — 5 часов.
2. Оптимизация запроса к данным для последних учебников — 3 часа.

Общая трудоемкость: 8 часов.

## Days off

Запланирован отпуск: 5 рабочих дней текущего спринта.

Из-за отсутствия участника фактически доступная емкость команды уменьшается.

## Изменение оценки

После уточнения задачи
«Добавить страницу для самых последних учебников»
оценка была увеличена с 5 до 8 часов.

Теперь:

- первая задача — 8 часов;
- вторая задача — 3 часа;
- общая трудоемкость — 11 часов.

Плановая емкость составляла 8 часов.

Перегрузка составляет 3 часа.
